# Power Automate-style workflow reference (illustrative)

**Status: Independently authored, untested reference example. Not the capstone implementation or a verified deployable package.**

This folder contains a substantial, generic Azure Logic Apps / Power Automate-style workflow JSON definition and synthetic examples. It demonstrates normalization, deterministic field checks, exception branching, a proposed routing record, and an audit summary. It does **not** contain exported organizational configuration, connections, tenant identifiers, authentication, AI Builder model bindings, or real invoice data.

## Contents
- `workflow-definition.json` — illustrative workflow definition with HTTP request/response actions and expressions.
- `sample-invoice.json` — synthetic valid-looking request.
- `sample-invalid-invoice.json` — synthetic exception-path request.
- `sample-approval.json` — independent example of a human decision; **not generated by the workflow**.
- `validation-rules.json` — design-level validation and scope flags.
- `test-scenarios.md` — proposed checks; none were executed on this reference.

## Intended conceptual sequence
1. Accept a structured invoice payload (not a PDF).
2. Normalize fields.
3. Apply a limited set of required-field/value checks.
4. Construct a routing recommendation requiring human verification.
5. Construct an illustrative audit summary and return a response.

## Important limitations
- This is **not** a Power Automate solution export and may need changes to import or execute in any environment.
- No PDF extraction, AI Builder integration, email triggers, ESM API integration, persistent duplicate detection, approval execution, Purchasing handoff, retry strategy, or durable audit storage is implemented in this example.
- It has not been run or integration-tested. Its sample data are fictional.
- The actual capstone MVP was built and evaluated separately; see the repository's main README and validation summary for supported claims.

## Security
No credentials, organizational endpoints, tenant IDs, connection references, mailbox IDs, or real invoice content were used in creating this example. Review any additions before publication.
